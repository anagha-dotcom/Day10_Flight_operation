# Day10_Flight_operation
# Flight Operations Data Analysis

## Day 10 – Complete Data Analysis Notebook

### Project Overview

This project presents a complete data analysis workflow using **Python and Pandas** on a Flight Operations dataset.

The analysis explores flight operations data to identify meaningful patterns related to airlines, routes, aircraft, passenger volumes, ticket prices, delays, weather conditions, booking channels, baggage, meal preferences, and passenger satisfaction.

The entire analysis is presented in a structured **Google Colab/Jupyter Notebook**.

## Dataset

The Flight Operations dataset contains **180 flight records and 17 columns**.

The major variables include:

* Flight ID
* Flight Date
* Airline
* Origin
* Destination
* Aircraft
* Travel Class
* Passengers
* Seat Capacity
* Average Ticket Price
* Delay Minutes
* Flight Status
* Weather
* Booking Channel
* Average Baggage
* Meal Preference
* Passenger Satisfaction

## Analysis Performed

The notebook follows a complete Pandas-based data analysis workflow:

* Loading the dataset
* Understanding the dataset structure
* Inspecting the first and last records
* Checking dataset shape and columns
* Examining data types and statistics
* Checking missing values
* Selecting relevant columns and records
* Filtering data based on conditions
* Sorting records
* Grouping data using `groupby()`
* Performing aggregation operations
* Applying suitable data transformations
* Analyzing flight operations and passenger-related patterns
* Identifying key findings and observations

## Tools and Technologies

* Python
* Pandas
* Google Colab / Jupyter Notebook

## Key Areas of Analysis

The analysis focuses on questions such as:

* How do flight operations vary across airlines?
* Which routes and destinations have higher passenger volumes?
* How are ticket prices distributed across travel classes?
* What patterns can be observed in flight delays?
* How does weather relate to flight status and delays?
* Which booking channels are commonly used?
* How do passenger satisfaction levels vary across flight characteristics?

## Key Observations

The notebook presents **5–8 observations** based on the analysis of flight operations, including patterns in passenger demand, ticket pricing, delays, weather conditions, booking channels, and passenger satisfaction.

## Conclusion

This project demonstrates the use of **Pandas for practical data analysis**, covering the complete workflow from dataset loading and inspection to filtering, sorting, grouping, aggregation, transformation, and interpretation of results.

The analysis provides meaningful insights into flight operations and demonstrates how structured data analysis can support better understanding of airline and passenger-related patterns.
